1. Objective & Constraints

This project demonstrates the team's DevOps bootcamp work using containerization, infrastructure automation, CI/CD and cloud deployment.

  • Docker Hub is banned.
  • The web application is the team's presentation.
  • The application must not run directly on EC2.
  • The application is designed for managed container deployment.
  • The team attempts the required bonus challenges.

2. Architecture

The presentation application is packaged as a Docker image and intended for deployment through Amazon ECR and Amazon ECS/Fargate.

bootcamp-project-arhitecture.html

The architecture documentation is maintained separately in the project documentation.

3. What Each Member Did

Team Member 2

AWS infrastructure, Terraform and cloud resources.

Team Member 3

Ansible/server work and architecture documentation.

Team Member 4

Jenkins CI/CD automation and deployment pipeline.

4. Pipeline Walkthrough

  1. Developer pushes code to Git.
  2. Jenkins obtains the source code.
  3. The application Docker image is built.
  4. Container health is tested.
  5. The image is pushed to Amazon ECR.
  6. ECS/Fargate pulls the image from ECR and runs the application container.
